# F00 API Documentation

There is no Spring Boot API in this repository at F00 completion. Consequently, no executable OpenAPI/Swagger document is generated and no endpoint is claimed.

The target contract is Spring MVC/WebFlux controllers protected by JWT/OIDC, documented from code through `/v3/api-docs` and Swagger UI. F01 must document the identity/bootstrap endpoints and their authorization; each later feature must add endpoint schemas, error contracts, idempotency behavior, and authorization rules alongside executable controllers.

Legacy browser-direct Supabase queries are not public APIs and must not be copied into Swagger.
